# fullstack_developer_capstone

## About the Project

This project is a full-stack car dealership application developed as part of the IBM Full Stack Software Developer Capstone Project.

The application allows users to browse car dealerships, view dealership details, read customer reviews, and submit reviews after logging in. It includes a Django backend and a React frontend.

## Features

- User login and logout
- Browse car dealerships
- Filter dealerships by state
- View dealership details and customer reviews
- Submit customer reviews
- Analyze review sentiment
- Django administration interface

## Technologies Used

- **Frontend:** React, JavaScript, HTML, CSS, Bootstrap
- **Backend:** Python, Django
- **Database:** As configured in the project
- **Version Control:** Git and GitHub

## Project Structure

The project contains frontend and backend components for the car dealership application.

## Running the Application

Run the Django backend and React frontend using the setup and commands provided in the project files.
